# Obsidian

**Obsidian** edits a folder of Markdown files (a *vault*) and turns the links between them into a navigable knowledge graph. Files stay on your disk in plain text, which makes a vault both human-readable and easy for AI tools to read, index and write. This knowledge base is an Obsidian vault — open it and use the graph view to explore the connections.
