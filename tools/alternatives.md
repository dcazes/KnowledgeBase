# Tools Alternatives

| Tool | What it is | Main alternatives |
|---|---|---|
| [Frigate](frigate/index.md) | Local AI NVR | Blue Iris + CodeProject.AI, Scrypted, Shinobi, ZoneMinder, cloud cameras |
| [Obsidian](obsidian/index.md) | Local Markdown knowledge base with graph view | Logseq (open source, outliner), Notion (cloud), Anytype, Foam/Dendron (VS Code), SiYuan |
| [Pydantic](pydantic/index.md) | Python data validation and JSON Schema | msgspec, attrs + cattrs, marshmallow, dataclasses + jsonschema; Zod in TypeScript |

## Why these are here

* **Frigate** shows [local inference](../concepts/local-inference.md) outside chat: detection, embeddings and vision-language models on a home server.
* **Obsidian** is the front end of this knowledge base and a hand-built [knowledge graph](../concepts/knowledge-graphs.md).
* **Pydantic** underpins [structured output](../concepts/structured-output.md) and tool schemas across agent frameworks.
