# VS Code

**Visual Studio Code** is the world's most used code editor and the foundation many AI editors fork. Since 2025 its AI features — GitHub Copilot chat, agent mode, next-edit suggestions — have been open-sourced into the editor itself, and it is a first-class [MCP](../../concepts/mcp.md) client.
