# Zed — Installation

```bash
curl -f https://zed.dev/install.sh | sh        # macOS / Linux
brew install --cask zed                        # Homebrew
```

Windows builds and Linux distribution packages are available; see zed.dev/download. Sign in for collaboration and Zed-hosted models, or configure your own providers.
