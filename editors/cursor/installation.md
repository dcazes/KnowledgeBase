# Cursor — Installation

1. Download from cursor.com for macOS, Windows or Linux (AppImage/deb/rpm).
2. On first launch, import VS Code extensions, settings and keybindings.
3. Sign in; choose **privacy mode** if code must not be retained by model providers.
4. Pick default models, or add your own API keys in settings.

The Cursor CLI installs separately for terminal and CI use.
