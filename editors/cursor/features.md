# Cursor — Features

| Feature | What it does |
|---|---|
| Tab | Multi-line, cross-file next-edit predictions |
| Inline edit (Cmd/Ctrl+K) | Edit or generate code in place |
| Agent | Multi-file changes, terminal, search, lint loop; ask and plan modes |
| Cloud agents | Remote parallel agents that open PRs |
| Bugbot | Automated PR review on GitHub |
| @-context | `@file`, `@folder`, `@docs`, `@web`, `@git` |
| Rules & memories | Project rules (`.cursor/rules`), `AGENTS.md`, user rules |
| MCP | External tools and data via [MCP](../../concepts/mcp.md) |
| Marketplace | Plugins bundling MCP servers, rules and skills |
| Cursor CLI | The agent in a terminal |
