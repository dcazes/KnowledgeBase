# Continue — AI Integration

While installed, Continue works with [Ollama](../../runtime/ollama/index.md), [LM Studio](../../runtime/lmstudio/index.md), [vLLM](../../runtime/vllm/index.md) or a [LiteLLM](../../runtime/litellm/index.md) gateway and MCP servers.

## Maintained alternatives

| Want | Move to |
|---|---|
| IDE agent with local models | [VS Code](../vscode/ai-features.md) Copilot with bring-your-own models, or [Zed](../zed/index.md) |
| Open-source terminal agent | [OpenCode](../../agents/opencode/index.md), [Aider](../../agents/aider/index.md) |
| Strongest agent in the IDE | [Claude Code](../../agents/claude-code/index.md) or [Codex](../../agents/codex/index.md) extensions |
