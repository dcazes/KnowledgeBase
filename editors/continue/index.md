# Continue

**Continue** was the leading open-source AI coding extension: chat, autocomplete, edit and agent modes in VS Code and JetBrains, plus a CLI — all configurable with any model, including local ones. In 2026 the team published a **final 2.0 release** (removing telemetry and authentication) and made the repository **read-only**.
