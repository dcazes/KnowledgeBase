# Continue — Installation

* **VS Code:** install "Continue" from the Marketplace or Open VSX.
* **CLI:** install the Continue CLI per the docs (`cn`), recommended over the JetBrains plugin.
* **JetBrains:** plugin available but not recommended.

Configuration lives in `~/.continue/config.yaml`. As the project is archived, pin the version you use and plan a migration path.
