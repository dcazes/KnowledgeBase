# Open WebUI — Features

| Area | Highlights |
|---|---|
| Chat | Multiple models side by side, arena mode for blind comparison, branching, folders, tags, sharing |
| Knowledge | Upload documents or build knowledge collections; `#` to attach; cited answers ([RAG](rag.md)) |
| Web | Web search through many providers including [SearXNG](../../runtime/searxng/index.md); fetch URLs into context |
| Tools | Python tools and functions, community marketplace, external [MCP](../../concepts/mcp.md)/OpenAPI tool servers |
| Code | Code interpreter (Pyodide in-browser or Jupyter) and artifacts |
| Media | Image generation (ComfyUI, Automatic1111, OpenAI), speech-to-text and text-to-speech, voice/video call mode |
| Memory | Per-user memories injected into chats ([Agent memory](../../concepts/agent-memory.md)) |
| Collaboration | Notes, channels, shared prompts and models |
| Admin | RBAC, groups, model whitelists, usage and evaluation (thumbs feedback) |
