# Alternatives

| Tool | Model | Strengths | Fit here |
|---|---|---|---|
| **Supermemory** | personal AI memory (save → semantic Q&A) | simple end-user memory, local-first desktop | installed (app data present 2026-07) but idle |
| **Rewind** | screen-recording memory | captures everything visually | heavy (records screen); privacy trade-off |
| **Recall (Windows)** | timeline screenshots + local AI | OS-integrated | Windows-only |
| **Mem0 / MemOS** ([here](../mem0/index.md), [here](../memos/index.md)) | developer memory platforms | APIs/MCP, agent memory | the agent-stack choice here |
| **Obsidian** ([here](../obsidian/index.md)) | local-first PKM | full control, plugins, this vault | the main knowledge base here |
| **Notion / Anytype** | notes + databases | collaborative/docs | cloud or different philosophy |

## Choosing

* **Save-and-forget personal memory with AI Q&A** → Supermemory (already provisioned here).
* **Agent/developer memory** → Mem0/MemOS/Graphiti.
* **Structured personal knowledge base** → Obsidian (this vault).
* **Everything-captured (visual)** → Rewind.
